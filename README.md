Sistema de Médias dos Alunos (PROJETO 1)

SOBRE O PROJETO

Este projeto foi desenvolvido em linguagem C para a disciplina de Introdução às Técnicas de Programação (ITP).
O programa permite cadastrar alunos, registrar suas notas e calcular suas médias, apresentando a situação de cada aluno e os resultados gerais da turma.

FUNCIONALIDADES

-Cadastro de 1 a 10 alunos.

-Registro do nome de cada aluno.

-Entrada de três notas por aluno.

-Validação da quantidade de alunos e das notas informadas.

-Cálculo da média individual de cada aluno.

-Verificação da situação do aluno, considerando a média mínima de 6,0.

-Cálculo da média geral da turma.

-Identificação da maior média.

-Exibição de todos os alunos que obtiveram a maior média, incluindo empates.

-Alocação dinâmica de memória para armazenar as médias.

COMO EXECUTAR O PROGRAMA?

1- Baixe ou clone este repositório.

2- Abra o arquivo avaliacao_itp_2.c em um ambiente de desenvolvimento compatível com a linguagem C.

3- Compile o código.

4- Execute o programa.

5- Informe a quantidade de alunos, seus nomes e suas respectivas notas. O programa apresentará os resultados após a entrada de todos os dados.
